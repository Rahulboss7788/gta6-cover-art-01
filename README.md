Vice Cover Studio — a GTA 6-style cover art maker that runs fully offline in a desktop browser. Drop in your own photos, arrange them across three multi-panel poster layouts (Sunset Strip, Neon Grid, Hero Duo), crop and position each panel by dragging, pick a Vice City sunset or neon colour grade, set a big bold caption, and export a PNG at 1080×1080, 1080×1350 or 1920×1080. Everything is original: no game logos, artwork or fonts — display type is Anton and Archivo Black under the SIL Open Font License, and the two sample photos were made for make.fun.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — add a photo (or try a sample), drag it into place, write a caption, and hit Download PNG. No build step, no network, no sign-in; photos never leave your machine.
